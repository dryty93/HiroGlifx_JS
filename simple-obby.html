Game-building vocabulary

Start a stage and create a platform:

stage 1 "Bubble Run" platform start at 0 0 0 size 5

Try moving and disappearing obstacles:

moving glide at 8 0 0 size 3 axis z range 1 period 3 vanishing ice at 12 0 0 size 3 delay 1.5

Save progress and reach the goal:

checkpoint safe at 16 0 0 size 4 spinner hazard at 20 0 0 size 2 range 1 period 3 finish goal at 24 0 0 size 5

You can also change theme soda to theme candy, or jump 10 to jump 12.
